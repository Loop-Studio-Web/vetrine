Getting started

Extract the ZIP file before installing the font.

A ZIP file is a container. Extract it before trying to install the font.

Windows

Right-click the ZIP file and select Extract All. Then right-click the OTF font file and select Install or Install for all users.

macOS

Double-click the ZIP file to extract it. Then double-click the OTF font file and select Install Font.

Phones and tablets

Downloading a ZIP file on a phone or tablet does not automatically install the font. Mobile installation varies by device and may require a font-management app or configuration profile.

If the font does not appear in your software, close and reopen the software after installing it.

Choosing the right file

Different font formats have different jobs.

OTF

Install on Windows or macOS for use in ordinary design, writing, presentation, and video software.

WOFF2

Use for live, selectable text on websites. WOFF2 files are available in the public-domain webfont package.

VFC

Open in FontLab to inspect or modify the font itself. These are source files for font development.

Not every download package contains every file type.
